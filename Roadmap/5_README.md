## ⚡ Common Pitfalls (Avoid These)

| Pitfall                 | What Happens                 | Solution                                   |
|-------------------------|------------------------------|--------------------------------------------|
| Skipping OOP/async      | Code is messy, hard to test  | Do Weeks 1–2 properly                      |
| All theory, no projects | Can't show in interviews     | Code every day                             |
| Projects only local     | No portfolio to show         | Deploy to free tier immediately            |
| No monitoring           | Bugs in production unnoticed | Use Langfuse from Week 3                   |
| No tests                | Code breaks on changes       | pytest from Week 1                         |
| Skipping error handling | API crashes on real load     | Add retry logic, logging early             |
| No documentation        | Can't explain your work      | README + architecture diagrams per project |
